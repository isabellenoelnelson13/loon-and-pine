# Loon & Pine

The coming-soon website for Loon & Pine, an independent fabric, notions, and handmade-goods shop.

## Stack

- Next.js
- React
- TypeScript
- CSS
- Vercel

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Import this repository into Vercel. Vercel will automatically run `npm run build` for each push to `main`.
